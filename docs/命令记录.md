## 1. 拉取代码

### 1.1 先试 HTTPS —— 失败（保留记录）

```bash
cd /e/work/frontEnd/cesium-vue-app
git clone https://github.com/156263847/cesium-vue-app.git .
```

结果：连接失败。逐层排查确认是**本机网络出口问题**：

```bash
# 查代理配置
git config --global --get http.proxy
git config --global --get https.proxy
echo "env: $HTTP_PROXY $HTTPS_PROXY $ALL_PROXY"

# 分站点测连通性
curl -s -o /dev/null -w "baidu:%{http_code}\n"     -m 10 https://www.baidu.com
curl -s -o /dev/null -w "github:%{http_code}\n"    -m 10 https://github.com
curl -s -o /dev/null -w "ghapi:%{http_code}\n"     -m 10 https://api.github.com
curl -s -o /dev/null -w "codeload:%{http_code}\n"  -m 10 https://codeload.github.com

# 绕过代理再试
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy \
  git -c http.proxy= -c https.proxy= clone https://github.com/156263847/cesium-vue-app.git .
```

**结论**：百度、`api.github.com`、`codeload.github.com` 都通，**唯独 `github.com:443` 不通**（代理报 `CONNECT tunnel failed, response 502`），关代理直连同样超时。

## 4. 网络诊断：为什么建筑白模取不到

排查顺序与实测结果（这组命令在换网络环境后**值得重跑一次**）：

```bash
# 4.1 Overpass 三个常用端点 + 影像/瓦片源
for u in "https://overpass.kumi.systems/api/interpreter" \
         "https://maps.mail.ru/osm/tools/overpass/api/interpreter" \
         "https://overpass-api.de/api/interpreter"; do
  printf "%-58s " "$u"; curl -s -o /dev/null -w "%{http_code}\n" -m 12 "$u"
done

# 4.2 关键证据：不带查询语句的 /api/status 也 406（说明是按域名拦截，不是查询写错）
for u in "https://overpass-api.de/api/status" \
         "https://z.overpass-api.de/api/status" \
         "https://lz4.overpass-api.de/api/status"; do
  printf "%-46s " "$u"; curl -s -o /dev/null -w "%{http_code}\n" -m 15 "$u"
done
```

**实测结论**：

| 端点 | 结果 |
|---|---|
| `overpass.kumi.systems` | 超时（000） |
| `maps.mail.ru` | 超时（000） |
| `overpass-api.de` 全家族（含 z./lz4.） | **406**，1 秒返回 nginx 错误页（156 字节） |
| `overpass.osm.ch` | 200，但只有瑞士数据，查北京返回 `elements: []` |

换 UA / `Accept: */*` / GET / POST / 极简查询 `node(1)` 全部 406 —— 出口按域名拦截，与代码无关。

```bash

curl -s -m 20 https://tiles.openfreemap.org/planet -o /tmp/tj.json

console.log('模板:', j.tiles[0]);

# 4.4 探测北京一个真实瓦片
curl -s -o /tmp/t14.pbf -w "code=%{http_code} size=%{size_download}\n" -m 25 \
```

## 6. 数据质量校验（抓完必跑）

### 6.1 统计与范围检查

```bash
cd /e/work/frontEnd/cesium-vue-app && node -e "
const a=require('./public/data/buildings-osm.json');
let pts=0,withH=0,hs=[],minLon=9e9,maxLon=-9e9,minLat=9e9,maxLat=-9e9;
for(const it of a){
  pts+=it.ring.length;
  if(it.tags.height){withH++;hs.push(+it.tags.height);}
  for(const [lon,lat] of it.ring){
    minLon=Math.min(minLon,lon);maxLon=Math.max(maxLon,lon);
    minLat=Math.min(minLat,lat);maxLat=Math.max(maxLat,lat);
  }
}
console.log('栋数',a.length);
console.log('坐标范围 lon',minLon.toFixed(5),maxLon.toFixed(5),' lat',minLat.toFixed(5),maxLat.toFixed(5));
console.log('总顶点',pts,'平均',(pts/a.length).toFixed(1));
console.log('带高度',withH,'/',a.length,
  hs.length?('min/max/avg='+Math.min(...hs)+'/'+Math.max(...hs)+'/'+(hs.reduce((s,v)=>s+v,0)/hs.length).toFixed(1)):'');
"
```

本次结果：**133 栋 / 28KB / 平均 6.6 顶点 / 133 栋全带高度（4–151m，均 10.4m）**，坐标范围与园区 bbox 吻合。

### 6.2 用 Cesium 几何管线验证每个环都能三角化

```bash
cd /e/work/frontEnd/cesium-vue-app && cat > _verify.mjs <<'EOF'
import * as Cesium from 'cesium'
import fs from 'node:fs'

const items = JSON.parse(fs.readFileSync('public/data/buildings-osm.json', 'utf8'))
let ok = 0, nul = 0, thrown = 0, badHeight = 0
const tris = []
for (const { ring, tags } of items) {
  const h = Number(tags.height)
  if (!Number.isFinite(h)) badHeight++
  const flat = []
  ring.forEach(([lon, lat]) => flat.push(lon, lat))
  try {
    const g = Cesium.PolygonGeometry.createGeometry(new Cesium.PolygonGeometry({
      polygonHierarchy: new Cesium.PolygonHierarchy(Cesium.Cartesian3.fromDegreesArray(flat)),
      vertexFormat: Cesium.PerInstanceColorAppearance.VERTEX_FORMAT,
      height: 0,
      extrudedHeight: Number.isFinite(h) ? h : 12
    }))
    if (g) { ok++; tris.push(g.indices.length / 3) } else { nul++ }
  } catch (e) { thrown++ }
}
console.log(`几何：成功 ${ok} / 空 ${nul} / 抛错 ${thrown} / 高度非法 ${badHeight}`)
console.log(`三角形 min/max/avg = ${Math.min(...tris)}/${Math.max(...tris)}/${(tris.reduce((a,b)=>a+b,0)/tris.length).toFixed(1)}`)
EOF
node _verify.mjs 2>&1 | tail -5
rm -f _verify.mjs
```

本次结果：**133/133 全部成功生成几何，三角形 12–112 个，无空、无抛错**。这条命令是排查"实体数对得上但建筑看不见"的第一只手。
